Unity VRM Animation Guide

VRM 1.0 動作套用與 VRMA 匯出教學
完成度：0%

📝 課前準備

  • 軟體：Unity Editor (建議使用 2021.3 或 2022.3 LTS 版本)。
  • 套件：最新版 UniVRM 1.0 (請下載 VRM-0.xxx.x.unitypackage，注意不要與 VRM 0.x 版本混淆)。
  • 素材：一個 .vrm 虛擬角色檔案，以及一個 .fbx 動作檔案 (例如從 Mixamo 下載)。

🚀 任務一：匯入 VRM 模型並套用 FBX 動作

將下載好的 VRM-0.xxx.x.unitypackage 拖曳進 Unity 下方的 Project 面板中安裝。接著，將準備好的 .vrm 檔案直接拖曳進 Project 面板，Unity 會自動解析並生成角色的 Prefab 檔案。將該 Prefab 拖曳到左側 Hierarchy 中放入場景。

將 .fbx 動作檔案拖曳進 Project 面板。點擊該 FBX 檔案，在右側的 Inspector 面板中切換到 Rig 標籤。

將 Animation Type 從 Generic 更改為 Humanoid，然後點擊右下角的 Apply。這能確保 FBX 的動作完美重定向 (Retargeting) 到 VRM 角色上。

在 Project 面板空白處點擊右鍵：Create -> Animator Controller，將其命名為 VRM_Anim。

點選 Hierarchy 中的 VRM 角色，在右側的 Animator 元件中，將剛剛建立的 VRM_Anim 拖曳到 Controller 欄位裡。

雙擊打開 VRM_Anim 進入 Animator 視窗。在 Project 面板中點擊 FBX 檔案旁邊的小三角形展開它，找到 Animation Clip (帶有三角形播放圖示的檔案)。

將該 Clip 拖曳進 Animator 視窗中，它會自動變成橘色的預設狀態 (Default State)。按下 Unity 頂部的 Play 播放鍵，角色就會開始動作了！

💾 任務二：將 FBX 動作匯出成 VRMA 檔案

VRMA (VRM Animation) 是專為 VRM 設計的動作格式。透過 UniVRM 1.0，我們可以將轉換好的動作獨立匯出，方便在其他網頁或應用程式中重複使用。

在 Project 面板中，選取剛剛展開的 FBX 檔案內的 Animation Clip。

在選取狀態下，點擊 Unity 頂部選單的 VRM1 -> VRM Animation Export (依 UniVRM 版本不同，也可能顯示為 Export VRMA)。此時會開啟動作匯出的設定視窗。

💡 提示：部分版本支援直接在 Hierarchy 選取掛載了 Animator 且設定好動作的 VRM 角色，再透過頂部選單匯出動作。

在彈出的匯出視窗中，找到 VRM 欄位（或是要求指定 Avatar 的欄位）。

將您在任務一匯入的 .vrm 角色 Prefab (或 Hierarchy 中的角色物件) 拖曳到這個欄位中。這個步驟非常重要，因為轉換器需要參考一個標準的 VRM 模型來讀取正確的骨架比例與對應關係。

確認視窗中沒有紅色的錯誤警告後，點擊右下角的 Export，設定檔名與存檔路徑，即可獲得標準的 .vrma 動作檔案！
